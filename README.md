# 🎓 교육과정 박람회 사이트 (고교학점제)

고등학교 **교육과정 박람회 · 과목 선택 안내**를 위한 무료 웹사이트 템플릿입니다.
학교 이름과 편성표 엑셀만 넣으면 **우리 학교 전용 사이트**가 됩니다.

| 구성 | 내용 |
|---|---|
| 🏠 고교학점제란? | 편제·학점배당·성적산출·우리 학교 편성표·수능 출제범위 |
| 📚 교과(군)별 과목 안내 | 2022 개정 155개 과목 상세(학점·성적산출·수능·Q&A) |
| 🎬 선택과목 길라잡이 영상 | 교과별 유튜브 영상 재생 |
| ✅ 과목 선택 체크리스트 | 학기별 과목 선택 → 구글 시트로 결과 제출 |
| 🎯 대학별 · 계열별 권장과목 | 2028학년도 대입 반영과목 표 |

## 🚀 우리 학교 사이트 만들기 (약 30분)

> 준비물: 깃허브 계정(무료), 구글 계정, 우리 학교 **학교알리미 「재학생의 3개년 교육과정 편성표」 엑셀**
> (학교알리미 → 학교 검색 → 교육활동 → 편성표 다운로드)

### 1단계. 내 저장소 만들기 (1분)
이 저장소 오른쪽 위 초록색 **[Use this template] → [Create a new repository]** 클릭
→ 저장소 이름 입력(영문, 예: `hanbit-fair`) → **Public** 확인 → [Create repository]

### 2단계. 사이트 켜기 (2분)
새 저장소에서 **Settings → Pages** →
Source: **Deploy from a branch** / Branch: **main**, **/ (root)** → **Save**
→ 1~3분 뒤 같은 화면에 표시되는 **내 사이트 주소**(`https://아이디.github.io/저장소이름/`) 확인

### 3단계. 우리 학교 설정 만들기 (10분)
내 사이트 주소 뒤에 **`#setup`** 을 붙여 접속 (예: `…github.io/hanbit-fair/#setup`)
1. 학교 이름·박람회명 등 입력
2. 영상 목록 수정(유튜브 주소 붙여넣기)
3. **편성표 엑셀 업로드** → 편성표·체크리스트 자동 생성 미리보기 확인
4. (결과 수집) 아래 [결과 수집 연결] 참고
5. **[⬇ school-config.js 다운로드]**

### 4단계. 설정 파일 올리기 (1분)
내 저장소 → **Add file → Upload files** → 받은 `school-config.js` 업로드 → **Commit changes**
→ 1~2분 뒤 사이트 새로고침(Ctrl+Shift+R)하면 우리 학교 버전 완성! 🎉

## 📩 결과 수집 연결 (택1)

학생이 [결과 제출]을 누르면 선택 과목이 **구글 시트에 과목별 1 체크 형태**로 쌓입니다.
`#setup` 페이지의 안내를 따라 아래 중 하나를 연결하세요.

- **방법 A · 접수 대행 (추천, 코드/배포 없음)** — 템플릿 시트 사본 → 헤더 메뉴 입력 → 운영자 계정에 편집자 공유 → 내 시트 URL을 설정에 입력
  ※ 운영자 계정이 시트에 접근 가능해지는 방식입니다. 원치 않으면 방법 B 사용.
- **방법 B · 독립 운영 (배포 1분)** — 템플릿 시트 사본(코드 자동 포함) → 헤더 메뉴 입력 → 시트의 Apps Script에서 **배포 → 웹 앱**(실행: 나 / 액세스: 모든 사용자) → `/exec` URL을 설정에 입력

## 📁 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 사이트 본체(공용 엔진) — **수정 불필요** |
| `school-config.js` | 우리 학교 설정(#setup에서 자동 생성) |
| `school-config.example.js` | 설정 파일이 어떻게 생겼는지 보는 견본 |
| `2028학년도_대학별_권장과목.xlsx` | 대학별 권장과목 원본(다운로드 버튼용) |
| `앱스크립트_제출연결.gs` | 결과 수집용 구글 앱스크립트(통합판) |

## ❓ 자주 묻는 질문

- **파일을 더블클릭해 열었더니 영상에 '오류 153'이 떠요** → 유튜브 정책상 로컬 파일(file://)에서는 재생이 막힙니다. 배포된 사이트 주소에서는 정상 재생돼요.
- **수정했는데 사이트에 반영이 안 돼요** → 반영에 1~2분 걸리고, 브라우저 캐시 때문일 수 있으니 Ctrl+Shift+R로 새로고침하세요.
- **편성표 업로드가 실패해요** → 학교알리미에서 받은 「재학생의 3개년 교육과정 편성표」 원본 그대로 올리세요(시트·열 구조를 자동 인식합니다).
- **화면 위에 노란 안내 띠가 보여요** → `school-config.js`가 아직 없다는 관리자용 안내입니다. 설정 파일을 올리면 사라져요.
