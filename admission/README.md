# 2028 대입 콘텐츠

독립 URL의 정적 HTML 본문을 제공하는 대입 허브와 서울대·고려대·연세대 상세페이지입니다.

- `2028/snu/article.json`, `2028/korea/article.json`: 제목·도입·본문 문단·FAQ·출처를 편집하는 글 파일입니다. HTML 코드를 수정하지 않고 글을 고칠 수 있습니다.
- 각 대학 폴더의 `data.json`: 공식자료 대조 후 정리한 학과별 데이터. 서울대는 유형 중복을 합치고 기존 행 번호를 유지합니다. 고려대는 2025-09-02 수정본을 사용합니다.
- `../tools/admission_universities.py`: 서울대·고려대 글과 데이터로 HTML을 만들고 기존 과목 설계 도구의 데이터를 동기화합니다. 직접 실행하지 않고 아래 생성기를 실행하세요.

- `2028/yonsei/data.json`: 검토된 연세대 서울캠퍼스 자료. 출처는 2026년 4월 대학 입학처 PDF입니다.
- `../tools/build_admission.py`: 데이터에서 상세페이지, 허브, sitemap과 기존 도구의 연세대 데이터를 생성합니다. 저장소 루트에서 `python tools/build_admission.py` 실행 후 생성된 파일도 커밋하세요. Python 표준 라이브러리만 사용합니다.
- `2028/admission.css`, `2028/admission.js`: 반응형 디자인과 점진적 검색 기능. JavaScript 없이도 모든 모집단위와 링크가 노출됩니다.
- 체크리스트는 검증된 `university`와 `unit` 쿼리를 받아 기존 보기와 설계 보드의 첫 목표 대학에 적용합니다. 이미 선택한 과목과 두 번째 목표 대학은 유지됩니다.

## 검증

`python tools/check_admission.py`로 데이터 동기화, 내부 링크, 구조화 데이터, 사이트맵과 URL 입력 검증을 확인합니다. `python -m http.server 8765 --bind 127.0.0.1`로 실행하면 `/admission/2028/`를 미리 볼 수 있습니다.

과학 진로선택의 3과목 이상/위계, 일반선택의 택 1 등 조건은 기존 도구의 과목명 매칭만으로 완전히 평가할 수 없습니다. 상세페이지와 도구의 비고에 원문 조건을 남겼으며, 과목 충족률을 대학의 평가 결과로 해석하면 안 됩니다.

## 배포와 확장

기존 GitHub Pages의 main 브랜치 배포 설정을 그대로 사용합니다. 파일을 해당 배포 브랜치에 반영하면 `/admission/2028/`와 그 아래 `snu/`, `korea/`, `yonsei/`가 공개됩니다. 사이트맵은 `/sitemap.xml`에 있습니다. 다른 대학은 공식자료 검토가 끝난 뒤 별도 페이지를 추가하세요. 준비 중인 빈 페이지는 생성하지 않습니다.

이 저장소는 프로젝트 하위 경로에 배포됩니다. 프로젝트 디렉터리의 `robots.txt`는 호스트 루트의 robots 정책을 대신할 수 없어 추가하지 않았습니다. Search Console 등에 사이트맵을 제출하려면 사이트 소유자의 관리 화면에서 해당 사이트맵 URL을 사용하세요.

다른 저장소로 복제할 경우 생성기의 `BASE`와 학교명·본문을 해당 사이트에 맞추세요. 대학 데이터의 순서는 `unit` 링크에 사용되므로 기존 행을 재정렬하지 말고 새 행을 끝에 추가하세요.
