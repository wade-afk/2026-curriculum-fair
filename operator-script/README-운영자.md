# 운영자 접수 스크립트 설치 (1회, 약 10분)

운영 전용 구글 계정으로 하는 것을 권장합니다 (개인 계정이 잠기면 전체가 멈춤).

## 1. 운영 시트 만들기
1. 구글 드라이브 → 새 스프레드시트 → 이름: `박람회 운영`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 편집기의 기본 코드를 지우고 `Code.gs` 내용을 전부 붙여넣기 → 💾 저장
4. 상단 `CONFIG`의 `SITE_URL`, `OPERATOR_NAME`만 확인해서 수정

## 2. 초기 설정
1. 시트로 돌아와 새로고침 → 메뉴에 **🎓 박람회 운영**이 생김
2. **1. 초기 설정** 클릭 → 권한 승인(첫 실행 시 "확인되지 않은 앱" 경고 → 고급 → 이동) → `학교`·`로그` 탭 생성

## 3. 웹 앱 배포
1. Apps Script 편집기 → 오른쪽 위 **배포 → 새 배포**
2. 유형 ⚙ → **웹 앱**
3. 실행: **나** / 액세스: **모든 사용자** → 배포
4. `/exec`로 끝나는 URL 복사 (메뉴 **3. 웹 앱 URL 확인**으로도 볼 수 있음)
5. 이 URL을 사이트의 `schools.json` 맨 위 `operatorUrl`에 넣음 (② 단계에서 연결)

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 4. 동작 확인
편집기에서 함수 선택 `test_registerAndSubmit` → ▶ 실행.
`학교` 탭에 `testschool` 행, 드라이브 `교육과정박람회_학교별결과` 폴더에 시트, 내 메일함에 안내 메일이 오면 정상.
확인 후 `testschool` 행은 지워도 됩니다.

## 운영 흐름
| 단계 | 누가 | 하는 일 |
|---|---|---|
| 신청 | 학교 선생님 | 사이트에서 학교·이메일 입력 → `학교` 탭에 `대기` 행 생김 + 운영자에게 메일 |
| 승인 | 운영자 | `상태`를 `승인`으로 바꾸고 메뉴 **2. 승인 처리 실행** (또는 **승인 자동 처리 켜기**로 자동화) |
| 자동 | 스크립트 | 학교 시트 생성 → 선생님 이메일에 편집자 공유 → 안내 메일 → `시트URL` 기록 |
| 제출 | 학생 | 사이트 [결과 제출] → 해당 학교 시트 `선택결과` 탭에 기록, `집계` 탭 자동 갱신 |
| 중지 | 운영자 | `상태`를 `중지`로 바꾸면 그 학교의 제출이 즉시 막힘 (구독 종료 등) |

## 학교 시트 형식
- `선택결과`: 제출시각·학번·학년·반·번호·이름·선택과목 + 과목별 1 체크(열 자동 추가). 같은 학번 재제출 시 갱신.
- `집계`: 과목별 전체/1·2·3학년 인원 (수식).
- `안내`: 사용법.

`CONFIG.TEMPLATE_SPREADSHEET_ID`에 기존 템플릿 시트 ID를 넣으면 새 형식 대신 그 템플릿의 사본으로 만들어집니다.

## 한도 (개인 Gmail 기준)
- 메일 하루 100통, 스크립트 실행 하루 90분 — 학교 수십 곳까지는 충분. 그 이상은 Workspace 계정 권장.
- 시트 1개 최대 1,000만 셀 — 학교당 수천 명이어도 여유.
