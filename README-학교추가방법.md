# 학교 추가 방법 (2026 교육과정 박람회)

사이트 구조
- `index.html` — 사이트 본체 (고교학점제 안내·과목 설명은 모든 학교 공통)
- `schools.json` — 지역 › 구·군 › 학교 목록
- `schools/*.xlsx` — 학교알리미 "재학생의 3개년 교육과정 편성표" 원본 엑셀

새 학교를 넣는 순서
1. 학교알리미에서 그 학교의 `재학생의 3개년 교육과정 편성표.xlsx`를 내려받는다.
2. 파일 이름을 영문으로 바꿔 `schools/` 폴더에 올린다. (예: `schools/gyeyang.xlsx`)
3. `schools.json`의 해당 구·군 `schools` 배열에 한 줄 추가한다.

```json
{ "id": "gyeyang", "name": "계양고등학교", "short": "계양고", "file": "schools/gyeyang.xlsx" }
```

- `id` : 영문·숫자만. 주소 공유용(`?school=gyeyang`)과 브라우저 저장 키로 쓰임. 바꾸지 말 것.
- `name` : 목록에 보이는 이름. 엑셀 2행에 정식 학교명이 있으면 그 이름을 우선 씀.
- `short` : 상단 로고 한 글자에 쓰이는 줄임말(첫 글자만 사용).
- `file` : 엑셀 경로. 없으면(작전고처럼 `"builtin": true`) 사이트에 내장된 기본 편성표를 씀.
- 선택 항목: `submitUrl`(체크리스트 제출용 Apps Script 주소), `sheetId`, `planSheet`/`ckSheet`(시트 이름 직접 지정).
  `submitUrl`·`sheetId`가 없는 학교는 '결과 제출' 버튼이 숨겨짐(다른 학교 시트로 제출되는 것 방지).

새 구·군이나 지역은 같은 모양으로 `districts` / `regions` 배열에 추가하면 된다.

엑셀을 새 파일로 교체했을 때
- `schools.json` 맨 위 `version` 값을 바꾸면(예: 날짜) 방문자 브라우저에 저장돼 있던 옛 편성표가 자동으로 새로 읽힌다.

동작 방식
- 학교를 고르면 브라우저가 엑셀을 내려받아 편성표 표와 과목 선택 체크리스트를 만들고, 선택을 저장한 뒤 새로고침한다.
- 편성표 표는 `전체학년` 시트, 체크리스트는 가장 최근 `○○○○ 입학생` 시트를 기준으로 만든다.
- 학교별 체크리스트 선택 내용은 따로 저장된다.

결과 수집 (운영자 접수)
- `schools.json`의 `operatorUrl`이 운영자 앱스크립트 주소입니다. (`operator-script/` 폴더 참고)
- 승인 여부는 사이트가 열릴 때 스크립트에 물어보므로, 학교를 승인·중지할 때 `schools.json`을 고칠 필요가 없습니다.
- 학교가 자체 앱스크립트를 쓰려면 그 학교 항목에 `submitUrl`을 넣으면 운영자 접수보다 우선합니다.


학교 전용 주소(잠금 링크)
- `사이트주소/s/<학교id>/` 가 그 학교로 고정된(잠긴) 짧은 주소입니다. 저장소의 `404.html`이 처리하므로 **학교별 폴더를 만들 필요가 없습니다.** `schools.json`에 학교를 추가하면 주소도 바로 생깁니다.
- 잠긴 주소(`?school=id&lock=1`)로 들어오면 학교 선택 바가 숨겨지고 학교 전환이 되지 않습니다. 기본 주소는 항상 작전고로 열리고 마지막 학교를 기억하지 않습니다.
- 승인 메일에 이 주소와 QR이 자동으로 포함됩니다 (operator-script 참고).
